# 项目说明

## 一句话介绍

薯店种草助手是一款面向小红书电商运营的本地桌面工具，用于管理商品资料、生成多种风格的带货笔记，并统一安排立即或定时发布任务。

## 项目背景

电商内容运营中存在大量重复工作：整理商品卖点、编写不同角度的笔记、录入标题和标签、上传图片、选择商品并安排发布时间。手工处理不仅耗时，也容易出现漏填、错填和任务状态不清的问题。

本项目将这些环节整合为一个桌面工作流，使运营人员可以在同一界面中完成商品录入、AI 文案生成、人工修改、账号选择和发布任务管理。

## 主要功能

### 1. 商品库

集中保存商品名称、主图、店内商品 ID、卖点和标签，减少重复整理资料。

### 2. AI 文案生成

根据商品信息生成种草、测评、促销和场景化文案。生成结果可以继续人工修改，避免直接使用未经检查的内容。

### 3. 发布任务

支持立即发布和定时发布，并记录待发布、发布中、已发布、失败和已取消等状态。

### 4. 多账号

每个账号绑定独立登录态，发布任务明确指定目标账号，避免账号混用。

### 5. 自动化发布

通过 Playwright 模拟浏览器操作，完成上传图片、填写标题正文、添加标签和挂载商品等步骤。

## 技术实现

- 使用 PyQt5 构建桌面界面
- 使用 SQLite 保存商品、账号和任务数据
- 使用 Playwright 执行浏览器自动化
- 使用 OpenAI Compatible API 生成内容
- 使用 Python logging 记录运行日志
- 使用 unittest 覆盖核心数据流程

## 设计重点

### 本地运行

项目不依赖服务器，商品资料和任务默认保存在本机，部署成本较低。

### 人工可控

AI 生成内容后仍需人工选择和编辑。商品挂载失败时默认停止发布，避免错误内容继续提交。

### 模块化

界面、数据访问、内容生成和自动发布分别放在独立模块中，后续可以单独维护和扩展。

### 可演示

未配置 API Key 时，项目会使用离线演示生成器，仍然可以展示商品管理、内容生成和任务管理流程。

## 面试介绍参考

这个项目主要解决小红书电商运营中重复整理商品资料、反复写文案和手工安排发布的问题。我把完整流程拆成商品管理、AI 文案生成、发布任务和账号管理四个模块。界面使用 PyQt5，数据保存在本地 SQLite，内容生成对接兼容 OpenAI 格式的接口，自动发布使用 Playwright。为了避免自动化误操作，商品挂载失败时默认终止任务，程序异常退出后也会恢复卡住的任务状态。当前版本主要用于展示完整业务流程，后续计划继续优化商品匹配、发布确认和素材批量管理。

## 当前边界

- 自动化流程依赖平台页面结构
- 不绕过验证码、滑块或平台风控
- 定时发布要求程序持续运行
- 不包含库存、订单和复杂经营分析
- 正式账号使用前需要先通过测试账号验证
